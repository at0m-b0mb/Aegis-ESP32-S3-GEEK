What "listen-only" means here. Aegis is built from receive paths only: the BLE stack is compiled as a NimBLE observer with the broadcaster and peripheral roles disabled, and the Wi-Fi radio runs in promiscuous (monitor) mode. It captures no payloads, decrypts nothing, and emits no Wi-Fi frame or BLE advertisement.

The five detectors

Deauth / disassoc flood — clients kicked offline
Evil-twin / rogue AP — a look-alike of a network you trust
Beacon flood — fake-AP storms (mdk3/mdk4)
BLE tracker — an AirTag / Tile / SmartTag following you
BLE pairing-spam — Continuity / Fast Pair / Swift Pair pop-up floods
⚖️ Authorised use only. Aegis is a defensive, listen-only tool — but even passive monitoring is regulated in some places, and acting on what it shows you is your responsibility. Use it only on airspace you own or are authorised to assess. Read the safety & ethics notes first.

Browser
Chrome / Edge, desktop
Image
single file, flashed at 0x0

Steps

  1. Plug the GEEK into a USB-A port on your computer (or a USB-A data extension). USB-C-only laptop? Use an A-to-C adapter.
  2. Click Install Aegis and choose the board's serial port. (If none appears, hold BOOT while plugging in.)
  3. Let it erase and write — about a minute. Keep it plugged in.
  4. It reboots into Aegis: the splash, then the live radar. A serial console also runs at 115200.
Heads-up on this build. The detection engines, the microSD evidence log and the serial alerts are all live. The 1.14″ LCD bring-up (orientation / colour order) is the one thing not yet validated on physical hardware — if the screen looks rotated or off-colour, that's the known tweak, not a flashing failure.
